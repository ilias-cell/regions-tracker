# 🗺️ Регионы России — семейное соревнование

Веб-приложение для отслеживания, кто из членов семьи посетил больше регионов России.
Сводная таблица по 85 субъектам РФ, сгруппированным по федеральным округам, с прогресс-барами и лидербордом для 4 участников.

## Стек
- **Python** + **Flask**
- **SQLite** (данные хранятся в файле)
- Деплой на **Render.com**

## Локальный запуск

```bash
pip install -r requirements.txt
python app.py
```

Откройте http://localhost:5000

БД `tracker.db` создаётся автоматически при первом запуске и наполняется списком регионов.

## Как пользоваться
- Клик по ячейке в таблице — отметить/снять посещение региона игроком (✓).
- Итоги и прогресс-бары в лидерборде обновляются мгновенно.
- Клик по имени игрока в карточке — переименование.

## Деплой на Render.com

1. Залейте проект в репозиторий GitHub/GitLab.
2. На Render нажмите **New → Blueprint** и укажите репозиторий — Render прочитает `render.yaml` и создаст сервис автоматически.
   - Либо **New → Web Service** вручную:
     - Build Command: `pip install -r requirements.txt`
     - Start Command: `gunicorn app:app`
3. Важно: в `render.yaml` подключён постоянный диск (`/var/data`), чтобы БД
   не обнулялась при перезапусках. Переменная `DB_PATH` указывает на него.
   На бесплатном плане диск доступен — данные сохранятся между рестартами.

> Примечание: без постоянного диска файловая система Render эфемерна и SQLite-файл
> сбрасывается при каждом деплое/сне сервиса. `render.yaml` уже решает это.

## Настройка участников
Имена задаются в `app.py` (список `PEOPLE`) или меняются прямо в интерфейсе.
Список регионов — в `regions_data.py`.
